Questions

Is google-play-scraper free?

Yes, the Python and Node libraries are open source. You run and maintain them yourself.

Why use a hosted scraper?

No server, several languages merged in one run, monitoring of new reviews, schedules and exports, and someone else fixes it when Google changes its pages.

Which is cheapest?

Pandapi and thewolves both charge $0.10 per 1,000 reviews with no start fee.
