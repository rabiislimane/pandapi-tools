Extract tables from PDFs to Excel, in bulk

Copying a PDF table into Excel usually gives you one long column, merged cells or numbers stored as text. Here's what works for one file, what works for Python users, and how to turn hundreds of PDFs into clean spreadsheets without touching each one.

Updated 21 November 2026 · by the Pandapi team

One PDF: try the free routes first

  • Excel itself (Microsoft 365, Windows): Data › Get Data › From File › From PDF. Power Query lists the tables it finds. Good for clean, ruled tables; weak on borderless ones and tables that run across pages.
  • Online converters (Smallpdf, iLovePDF, Adobe): fine for one or two files a day on the free tiers, but you upload the document, and scanned PDFs need a paid plan.
  • Python: camelot (lattice mode for ruled tables, stream for whitespace tables) or tabula-py (needs Java). Great when you can tune them per layout; see Camelot vs Tabula.

If you only need the text, our free PDF to Markdown converter works in your browser with no upload and no limit.

Hundreds of PDFs: the API way

  1. Open the PDF to Excel API on Apify.
  2. Add PDF links, or upload a file in the console. Leave tableDetection on all (ruled and borderless tables).
  3. Pick xlsx or csv. You get a workbook per PDF (one sheet per table) and a tables.xlsx with every table from the run, so 200 statements land in one file. Multi-page tables are joined and wrapped lines merged.
  4. Run. Each PDF row has an excelUrl to the workbook and the tables as JSON, so you can also load them straight into a database.
curl -X POST "https://api.apify.com/v2/acts/blueberry_rainstorm~pdf-to-text-markdown/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "urls": [
    {
      "url": "https://example.com/statements/2026-10.pdf"
    }
  ],
  "tableDetection": "all",
  "spreadsheetOutput": "xlsx",
  "numbersAsNumbers": true,
  "includeMarkdown": false
}'
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("blueberry_rainstorm/pdf-to-text-markdown").call(run_input={
    "urls": [
        {
            "url": "https://example.com/report.pdf"
        }
    ],
    "spreadsheetOutput": "xlsx"
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item["fileName"], item["tableCount"], item.get("excelUrl"))

What it costs

$3 per 1,000 PDFs, whatever their page count, plus $5 per 1,000 pages when OCR runs on scanned pages. 300 monthly bank statements cost $0.90. PDFs that fail are free. Apify's free $5 monthly credit covers about 1,600 PDFs.

Limits, honestly

  • Tables inside scanned images come out as OCR text, not as spreadsheet cells.
  • Very complex headers (three levels, merged across groups) may need a quick fix in Excel.
  • Password-protected PDFs need the password in the input.

Questions

How do I convert a PDF table to Excel for free?

In Microsoft 365, use Data › Get Data › From PDF. For text only, our free PDF to Markdown tool works in the browser. For many files, Apify's free $5 monthly credit covers about 1,600 PDFs through the API.

Can it convert bank statements to Excel?

Yes. Bank statements are usually borderless tables over several pages, which is the case the API was built for: columns from alignment, pages joined, amounts as real numbers.

Does it work on scanned PDFs?

It reads scanned pages with OCR in 12 languages and returns the text. Table cells are not detected on scanned pages yet.

Can I get CSV instead of Excel?

Yes. Set spreadsheetOutput to csv. You also get every table as JSON rows in the dataset.

Are my PDFs stored?

Files are processed in your own Apify account and the results stay in your storage, which you can delete at any time.
