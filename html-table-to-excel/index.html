    How to use it

    1. Select the table on the web page (drag from its first cell to its last), copy it with Ctrl+C and paste it here. To get every table, paste the page source instead (Ctrl+U, then Ctrl+A, Ctrl+C) or drop a saved .html file.
    2. Pick the tables you want in the list and click a name to preview it. Merged cells, header rows and footnote marks are handled for you.
    3. Download Excel (one sheet per table), CSV (a .zip when you pick several), or copy the table and paste it straight into Excel or Google Sheets.

    Questions

    Is my data uploaded?

    No. The HTML is read and the Excel file is made in your browser, so tables from intranet pages, admin panels or private reports never leave your computer.

    Can I paste a URL?

    Not here: a page running in your browser can't fetch other websites. Copy the table from the page, paste the page source, or drop a saved .html file. To pull tables from many URLs automatically, use the Web Page to Markdown API linked on this page.

    What happens to merged cells?

    A cell that spans several rows or columns is repeated in each of them, so every row is complete for sorting and filtering. Choose “first cell only” to leave the others empty, like the original layout.

    Why do some numbers stay as text?

    Values like 007 or long ID numbers stay text so Excel doesn't drop the zeros or round them. Numbers with thousands separators (1,234.5), accounting minus signs ((12)) and the − sign become real numbers. Tick “strip $ € £ and %” to turn $12.50 or 45% into numbers too.

    Does it work with Wikipedia tables?

    Yes. Footnote marks like [1] and hidden sort keys are removed, stacked header rows become names like “Population / Metro”, and each table gets its caption or section heading as its name.
