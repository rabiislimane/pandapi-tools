    How to use it

    1. Drop your PDFs on the box, or click it to choose files. Several files are converted one after another.
    2. Check the Markdown of the first file on the right. Headings come from the font sizes, lists and contents entries are kept, and broken lines and hyphenated words are joined.
    3. Download one .md file, or a .zip with one .md per PDF.
    4. Turn on Mark page breaks if you need page numbers for citations (it adds <!-- page 3 --> comments).

    Questions

    Are my PDFs uploaded?

    No. They are read in your browser with Mozilla's pdf.js. Nothing is sent to a server, which is why there is no size limit, no daily limit and no account.

    Does it work on scanned PDFs?

    Not on its own. A scanned page is a picture with no text layer, and this page has no OCR. The tool tells you when a file looks scanned. The PDF API linked below reads scans with OCR in 12 languages.

    What happens to tables?

    Each table row comes out on its own line with cells separated by |, which keeps the data readable. For real spreadsheets (numbers you can sum, tables joined across pages), use the PDF API, which exports Excel and CSV.

    How are headings found?

    From font sizes: text clearly larger than the body text and used for short lines becomes #, ## or ### headings. Two-column pages, like research papers, are read column by column.

    Is it good for ChatGPT, Claude or RAG?

    Yes. Markdown keeps headings and lists that models use for context, and dropping repeated headers and page numbers saves tokens. The tool shows a token estimate for each file.
