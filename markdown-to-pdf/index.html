      How to use it

      1. Paste Markdown in the left box, or drop a .md file. The preview shows how it will look. If your Markdown uses images, add the image files in the Images box (or paste a screenshot into the text).
      2. Pick the page size, margins and text size. Turn on Table of contents for a contents page whose entries link to each heading, and Each # heading on a new page for chapters. Put <!-- pagebreak --> on its own line wherever you want a new page.
      3. Click Download PDF. The PDF has real text you can select and search, page numbers, working links and a title from your first heading or front matter.
      4. Writing in Chinese, Japanese, Korean, Arabic, Hebrew or with emoji? Use Print / Save as PDF: it uses your browser's own PDF engine, which has fonts for every language.
      5. For many files, drop them all at once and get a .zip of PDFs, or tick Combine them into one PDF.

      Questions

      Is my Markdown uploaded?

      No. The PDF is made in your browser with open-source libraries (marked, highlight.js and pdfmake), so notes, specs and drafts never leave your computer. The page works offline once it has loaded.

      Is there a limit or a watermark?

      No. Convert as many documents as you like, as often as you like. There is no account, no daily limit and no watermark.

      Is the text in the PDF real text?

      Yes. The PDF has vector text with embedded fonts, not a picture of the page, so it stays sharp when you zoom, the file is small, and you can select, copy and search the text. Links and the table of contents are clickable.

      Which Markdown does it support?

      GitHub Flavored Markdown: headings, bold, italic, strikethrough, links, lists, task lists, tables with alignment, code blocks with colors for common languages, block quotes, GitHub alerts like [!NOTE], images, horizontal rules and YAML front matter (title, author, date). Math and Mermaid diagrams are shown as their source text.

      Why are some characters missing from my PDF?

      Download PDF embeds fonts for Latin, Greek and Cyrillic text. For Chinese, Japanese, Korean, Arabic, Hebrew, Indian scripts or emoji, click Print / Save as PDF and choose "Save as PDF" as the printer: your browser has fonts for those.
