Screenshot a list of URLs: full page, desktop and mobile, in one run

For one page, your browser can take a full-page screenshot. For 200 client sites, a landing-page audit or weekly visual records, you want a list in and a folder of images out.

Updated 21 November 2026 · by the Pandapi team

Website Screenshot API: $4 per 1,000 screenshots. Apify's free plan gives you $5 of credit every month, which covers about 1,250 screenshots a month. No start fee; failed items are free.

Try Website Screenshot API

The free way: one page

In Chrome, open DevTools (F12), press Ctrl+Shift+P (Cmd+Shift+P on Mac), type screenshot and choose Capture full size screenshot. Firefox has Take Screenshot › Save full page in the right-click menu. For mobile, switch DevTools to device mode first. Great for one page, slow for fifty.

With code, Playwright does it in a few lines (page.screenshot(full_page=True)), and you handle the browser, cookie pop-ups, lazy images and failures yourself.

The API way: a list in, images out

  1. Open the Website Screenshot API on Apify.
  2. Paste your URLs. Choose devices (desktop, mobile, tablet), full page or viewport, and PNG, JPEG or PDF.
  3. Leave hideCookieBanners on. Add a delay or a selector to wait for if a page animates in.
  4. Run it. Each row has a screenshotUrl link that opens the image, plus the page title and HTTP status.
curl -X POST "https://api.apify.com/v2/acts/blueberry_rainstorm~website-screenshot/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "urls": [
    {
      "url": "https://apify.com"
    },
    {
      "url": "https://en.wikipedia.org/wiki/Web_scraping"
    }
  ],
  "devices": [
    "desktop",
    "mobile"
  ],
  "fullPage": true,
  "format": "png"
}'
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("blueberry_rainstorm/website-screenshot").call(run_input={
    "urls": [
        {
            "url": "https://example.com"
        }
    ],
    "devices": [
        "desktop"
    ],
    "format": "jpeg"
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item["url"], item["status"], item.get("screenshotUrl"))

What it costs

$4 per 1,000 screenshots; failed pages are free and pages that answer 4xx/5xx are reported as failures, not charged. 250 sites on desktop and mobile (500 shots) cost $2. Apify's free credit covers about 1,250 shots a month. Comparing with subscription screenshot APIs? See ScreenshotOne alternatives.

Limits

  • No logins: pages behind a sign-in come out as the sign-in page.
  • Very long pages are cut at maxHeightPx (15,000 px by default) to keep images usable.

Questions

How do I screenshot multiple URLs at once?

Paste the list into the Website Screenshot API, pick devices and format, and run it. You get one image link per URL and device.

Can it take full-page screenshots?

Yes, fullPage is on by default, with lazy images loaded and cookie banners hidden.

Can I get a PDF instead of an image?

Yes, set format to pdf. For proper printable documents with page sizes and headers, use the HTML to PDF API.

Do failed screenshots cost money?

No. You pay only for screenshots that succeed.
