UK Contracts Finder API: how to pull UK public contracts from code

The UK publishes public sector opportunities on two services: Contracts Finder for lower-value contracts and Find a Tender for contracts above the thresholds. Both have free APIs with no key. This page shows a working request, what to watch for, and how to get both as one daily feed.

The free way: the Contracts Finder OCDS search

Contracts Finder serves notices as Open Contracting (OCDS) JSON at /Published/Notices/OCDS/Search. You filter by publication dates and stage, and page through the results with the links.next cursor. There is no keyword parameter on this endpoint, so the example filters titles and descriptions in Python. No API key is needed (we checked on 23 November 2026).

import requests

url = "https://www.contractsfinder.service.gov.uk/Published/Notices/OCDS/Search"
params = {"publishedFrom": "2026-11-16T00:00:00", "publishedTo": "2026-11-23T00:00:00",
          "stages": "tender", "limit": 100}
keywords = ["software", "cyber", "digital", "cloud"]
while url:
    data = requests.get(url, params=params, timeout=60).json()
    for r in data["releases"]:
        t = r["tender"]
        text = (t.get("title", "") + " " + t.get("description", "")).lower()
        if any(k in text for k in keywords):
            print(t.get("tenderPeriod", {}).get("endDate"), r["buyer"]["name"], "|", t["title"])
    url, params = data.get("links", {}).get("next"), None  # the next link already has the filters

Contracts Finder or Find a Tender?

Contracts FinderFind a Tender
CoversLower-value contracts from central government and the wider public sectorContracts above the UK procurement thresholds
Free APIOCDS search, no keyOCDS release packages (/api/1.0/ocdsReleasePackages), no key
FiltersPublished dates, stageUpdated dates, stage
Watch forNo keyword filter; buyers can publish the same opportunity on bothRate limits: too many requests return HTTP 429 and a wait

If you bid on UK work, you usually want both: the bigger tenders are on Find a Tender, the smaller and local ones on Contracts Finder.

The feed way: both UK services, keywords and only new notices

  1. Open the Government Tenders API on Apify.
  2. Set sources to ["uk-cf", "uk-fts"] and add your keywords, and optionally CPV prefixes, a minimum value and the days left before the deadline.
  3. Turn on onlyNew with a stateKey so each run returns only notices you haven't seen, and schedule it daily.
  4. Send results to Google Sheets, Slack or email with Apify's integrations, or read them from n8n, Make or code.
curl -X POST "https://api.apify.com/v2/acts/blueberry_rainstorm~public-tenders-feed/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "sources": [
    "uk-cf",
    "uk-fts"
  ],
  "keywords": [
    "software",
    "cyber security",
    "digital"
  ],
  "noticeTypes": [
    "tender",
    "pre-notice"
  ],
  "postedWithinDays": 7,
  "minDaysLeft": 7,
  "onlyNew": true,
  "stateKey": "uk-digital"
}'
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("blueberry_rainstorm/public-tenders-feed").call(run_input={
    "sources": [
        "uk-cf",
        "uk-fts"
    ],
    "keywords": [
        "grounds maintenance"
    ],
    "postedWithinDays": 3
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item["source"], item["buyerName"], item["title"], item.get("deadline"))

Every notice comes back with the same fields as SAM.gov, TED and Canada notices: title, buyer, notice type, published date, deadline and days left, value in GBP and in USD/EUR, CPV codes and the link to the official notice.

What it costs

Both UK APIs are free. The feed costs $2 per 1,000 notices with no start fee, so a daily UK alert that finds 20 new notices costs about $0.04 a day. Apify's free $5 monthly credit covers about 2,500 notices.

Limits

  • Some councils and NHS bodies also publish on their own e-tendering portals; those notices only appear if they are also on Contracts Finder or Find a Tender.
  • Tender documents are linked, not downloaded.

Questions

Does Contracts Finder have an API?

Yes. Contracts Finder publishes notices as OCDS JSON at https://www.contractsfinder.service.gov.uk/Published/Notices/OCDS/Search. You filter by published dates and stage and follow the links.next cursor. It needs no API key.

Is the Contracts Finder API free?

Yes, it's free and open. The cost is your time: there is no keyword filter on the OCDS search, so you filter text yourself, and you track which notices you've already seen.

What is the difference between Contracts Finder and Find a Tender?

Contracts Finder lists lower-value UK public contracts; Find a Tender lists contracts above the UK procurement thresholds. Both have free OCDS APIs, and many bidders watch both.

How do I get daily UK tender alerts?

Use the Pandapi feed with sources uk-cf and uk-fts, onlyNew and a stateKey, schedule it daily on Apify, and add an email, Slack or Google Sheets integration.
