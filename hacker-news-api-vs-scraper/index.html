Questions

Is the Hacker News API free?

Yes, both the Firebase API and the Algolia search API are free and need no key.

How do I get more than 1,000 search results?

Split the query by date ranges with numericFilters on created_at_i, or use a scraper that does it for you.

Which API has comments?

Both. Firebase gives comment trees by item ID; Algolia can search comments by keyword.
