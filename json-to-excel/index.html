How to use it

  1. Paste JSON or drop a file. The tool finds the list of records itself, even inside an API response like {"data": {"results": [...]}}.
  2. Choose what to do with lists: join them in one cell, give each item its own row (an order with 3 lines becomes 3 rows), or its own columns.
  3. Check the preview, then download Excel (.xlsx) or CSV. Pick semicolons if your Excel uses commas for decimals.

Questions

Is my data uploaded?

No. Parsing and the Excel file are both made in your browser, so customer exports and API keys inside the data never leave your computer. There is no size limit beyond your computer's memory.

Why .xlsx instead of CSV?

Excel changes CSV data as it opens it: 007 becomes 7, long IDs turn into 1.23E+15 and accented letters can break. The .xlsx keeps text as text and numbers as numbers, with a bold, frozen header row and filters.

How is nested JSON flattened?

Nested objects become dot columns (buyer.name, buyer.country). Lists of values are joined in one cell, and lists of objects can be joined as JSON, split into one row per item, or spread into numbered columns.

Which JSON shapes work?

An array of objects, a single object, an object that wraps the records (items, data, results...), arrays of arrays with a header row, and JSON Lines / NDJSON with one object per line, like Apify dataset exports.

What is formula injection?

A cell that starts with =, +, - or @ can run as a formula when a CSV is opened in Excel. With the option on, such text cells get a leading apostrophe so they show as text. Numbers are not touched.
