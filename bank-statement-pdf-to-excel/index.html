Convert bank statement PDFs to Excel, in bulk

Accountants and bookkeepers get statements as PDFs and need them in Excel, Xero, QuickBooks or Tally. Statements are the hardest PDF tables: no lines between columns, descriptions that wrap, and transactions that run over many pages.

Why statements break converters

  • No ruling lines, so tools that look for cell borders find nothing.
  • The transaction table continues on every page, with the header repeated.
  • Long descriptions wrap onto a second line and become a fake row.
  • Amounts like 1,204.50 or (85.00) land as text.

Free route for one statement

Try Excel's Data › Get Data › From PDF first. If columns run together, Tabula's desktop app lets you draw the table area and pick "stream" mode. Check that the closing balance matches before you trust it.

Many statements: the API route

  1. Open the PDF to Excel API on Apify.
  2. Add the statement PDFs (links, or upload in the console). Add the password if the bank protects them.
  3. Keep mergeMultiPageTables and numbersAsNumbers on and pick xlsx. Each statement gets its own workbook, and tables.xlsx collects every statement's tables in one file.
  4. Run, download the workbook, and check the balance column sums.
curl -X POST "https://api.apify.com/v2/acts/blueberry_rainstorm~pdf-to-text-markdown/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "urls": [
    {
      "url": "https://example.com/statements/2026-09.pdf"
    },
    {
      "url": "https://example.com/statements/2026-10.pdf"
    }
  ],
  "spreadsheetOutput": "xlsx",
  "mergeMultiPageTables": true,
  "numbersAsNumbers": true
}'

Questions

How do I convert a bank statement PDF to Excel for free?

Try Excel's PDF import or Tabula's stream mode for one statement. For many, Apify's free $5 monthly credit covers about 1,600 PDFs through the Pandapi PDF API.

Will the numbers be real numbers?

Yes, with numbersAsNumbers on: separators and currency signs are removed and bracketed amounts become negatives.

Does it work with scanned statements?

It returns OCR text for scanned pages, but doesn't rebuild table cells from scans yet. Digital PDFs from online banking work best.
