Find broken links on any website, and the page each one is on

Broken links lose visitors and waste crawl budget. The hard part isn't finding a 404, it's knowing which page links to it so you can fix it. Here's how to do it free, and how to run it on a schedule.

Updated 21 November 2026 · by the Pandapi team

Free ways

  • Google Search Console › Pages › Not found (404): shows 404 URLs Google found, with some referring pages. Free and slow to update.
  • Screaming Frog SEO Spider (desktop): the free version crawls up to 500 URLs per crawl. See Screaming Frog alternatives for bigger sites.
  • Our free link extractor: paste a page's HTML or a sitemap to list every link, then spot-check them.

The API way: crawl, check, report

  1. Open the Broken Link Checker on Apify.
  2. Enter your start URL, how many pages to crawl and whether to check external links and images.
  3. Turn on onlyBroken to get just the problems.
  4. Schedule it weekly and send results to Slack or email, so new 404s show up before your visitors find them.
curl -X POST "https://api.apify.com/v2/acts/blueberry_rainstorm~broken-link-checker/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "startUrls": [
    {
      "url": "https://example.com/"
    }
  ],
  "maxPagesToCrawl": 200,
  "checkExternalLinks": true,
  "onlyBroken": true
}'

Each row: the link, its HTTP status, a category (broken, blocked, error, ok), whether it redirects and where, internal or external, the page it was found on, its anchor text, and how many pages link to it.

What it costs

$0.80 per 1,000 links checked. A site with 3,000 links costs $2.40; Apify's free credit covers about 6,000 links a month. It doesn't use a browser, so it's fast, and it respects robots.txt.

Limits

  • Some sites (LinkedIn, some shops) block automated checks; those links are reported as blocked, not broken.
  • Links added by JavaScript after load are not seen.

Questions

How do I find broken links on my website for free?

Use Google Search Console's Not found report, Screaming Frog's free version (500 URLs per crawl), or the Broken Link Checker with Apify's free $5 monthly credit, which covers about 6,000 links.

Does it show where the broken link is?

Yes. Every broken link comes with the page it's on, its anchor text and how many pages link to it.

Does it check external links?

Yes, checkExternalLinks is on by default. Sites that block bots are marked blocked so they don't flood your report.

Can I check images too?

Yes, turn on checkImages to test image URLs as well.
