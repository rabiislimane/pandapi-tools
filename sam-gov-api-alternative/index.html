SAM.gov API alternatives for contract opportunities

SAM.gov's API is official and free, but it's built for occasional use: a personal key, and a low daily request limit unless your account has a role in SAM.gov. If you search every day across keywords, or also bid in Europe or Canada, here are the alternatives.

SAM.gov API limits

GSA's documentation lists 10 requests a day for a non-federal user with no role in SAM.gov, and 1,000 a day for a non-federal user with a role (for example an entity registration) or a system account. Every request needs your API key.

Questions

What is the SAM.gov API rate limit?

GSA documents 10 requests a day for a non-federal personal key with no SAM.gov role, and 1,000 a day with a role or a system account.

Can I search SAM.gov without an API key?

On the SAM.gov website, yes. For data in bulk, use a feed or scraper that handles access for you, such as the Pandapi Government Tenders API.

Does it include NAICS and set-asides?

Yes, for SAM.gov notices: NAICS, PSC, set-aside, response deadline and contacts where published.
