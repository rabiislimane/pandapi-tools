How to use it

  1. Drop one or more .docx files, or open your document in Word or Google Docs, select everything (Ctrl+A), copy and paste it into the box. Pasting keeps headings, lists, bold, italics, links and tables.
  2. Pick how to handle images: save them as files (the .zip has your Markdown and an images/ folder, linked by relative paths), embed them in the Markdown, or leave them out. Tick front matter to start each file with its title, author and dates.
  3. Download the .md file, the .zip with images, or copy the Markdown. With several files, use the menu above the Markdown to look at each one, and Download all to get every file in one .zip.

Questions

Is my document uploaded?

No. The .docx file is read and converted in your browser, so contracts, drafts and internal documents never leave your computer. The page works offline once it has loaded.

What is kept?

Headings (Title and Heading 1-6), bold, italics, strike-through, links, bullet and numbered lists with nesting, tables, footnotes and endnotes (as [^1] notes), block quotes, code styles and images with their alt text. Underline has no Markdown form, so it is dropped unless you keep it as <u>.

What happens to tables with merged cells?

Markdown tables can't merge cells, so a table with merged cells, or with lists inside its cells, is written as a small HTML table inside the Markdown. GitHub, Obsidian and most static site generators show it as a table. Simple tables become normal Markdown tables.

Can it read .doc files or password-protected documents?

No. Old .doc files (Word 97-2003) and encrypted documents use a different format. Open them in Word or LibreOffice, save as .docx, and drop that file here.

Why are images missing when I paste from Word?

When you copy from Word, the clipboard points to temporary image files that a browser isn't allowed to read. Drop the .docx file instead and every image comes out. Pasting from Google Docs keeps images as links.

Does it work for Google Docs?

Yes, two ways: paste straight from the document (the page fixes Google Docs' bold-everything clipboard), or use File > Download > Microsoft Word (.docx) and drop that file to get the images too.
