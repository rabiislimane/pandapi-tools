Camelot vs Tabula for PDF tables (and a no-code option)

Camelot

import camelot
tables = camelot.read_pdf("report.pdf", pages="1-end", flavor="lattice")  # or "stream"
print(tables[0].parsing_report)
tables.export("report.xlsx", f="excel")

Pick Camelot when you can look at the output and tune it: table_areas, columns and row_tol fix most stream-mode problems.

tabula-py

import tabula
dfs = tabula.read_pdf("report.pdf", pages="all", lattice=True)  # or stream=True
tabula.convert_into("report.pdf", "report.csv", output_format="csv", pages="all")

Pick tabula-py when Java is already there and the tables are simple. The Tabula desktop app is handy for drawing table areas by hand.

When neither is worth the time

Questions

Is Camelot better than Tabula?

On ruled tables they're close. Camelot gives you more control and a parsing report, which helps on borderless tables; tabula-py is simpler if Java is installed. Neither joins tables across pages.

Does Camelot need Java?

No. Camelot is pure Python with a Ghostscript or pdfium backend. tabula-py needs Java because it wraps Tabula.

Can either read scanned PDFs?

No. Both need a text layer. Run OCR first (for example OCRmyPDF), or use an API with OCR.
