    How to use it

    1. Paste a page's HTML (open the page, press Ctrl+U, then Ctrl+A and Ctrl+C), or select part of a page and copy it: the links come with it. Plain text with URLs and sitemap.xml files work too, and you can drop several saved pages at once.
    2. Add the page URL if the page doesn't name itself, so /about becomes a full URL and links are sorted into internal and external. Filter by type, search, or sort by URL, domain or how often a link is used.
    3. Download Excel (a Links sheet and a Domains sheet), CSV, or copy the URLs one per line. To find which links are broken, run the Broken Link Checker on your site.

    Questions

    Is my data uploaded?

    No. The page is read in your browser, so links from intranet pages, admin panels or pages behind a login never leave your computer.

    Can I paste a URL?

    Not here: a page running in your browser can't fetch other websites. Open the page, press Ctrl+U to see its source and paste that, or save the page (Ctrl+S) and drop the .html file. The Broken Link Checker linked on this page fetches whole sites for you.

    What counts as internal?

    A link to the same host as the page, with or without www. The page's own address comes from the Page URL box, or from the page's canonical link or base tag when it has one.

    What does nofollow mean here?

    The column says yes when the link's rel attribute has nofollow, sponsored or ugc, which tell search engines not to pass ranking credit. The Rel column shows the exact value.

    Does it read sitemap index files?

    Yes. A sitemap index lists its child sitemaps (Kind: Sitemap) and a normal sitemap lists its pages with last modified date, change frequency, priority and image count. Drop several sitemap files to merge them.
