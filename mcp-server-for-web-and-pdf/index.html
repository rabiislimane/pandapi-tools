One MCP server for web pages, PDFs, screenshots, reviews and tenders

Your AI agent needs to read a docs page, a PDF or a competitor's reviews. Most MCP servers do one thing, or load dozens of generic tools that eat your context window. This one gives an agent 14 focused tools with small definitions and answers in one call.

Updated 21 November 2026 · by the Pandapi team

Pandapi MCP Server: free server; each tool call costs that API's own price. Apify's free plan gives you $5 of credit every month, which covers the same $5 of monthly credit. No start fee; failed items are free.

How to connect

In Claude (web or desktop), Cursor, VS Code or any client that supports remote MCP servers, add this URL and sign in with your Apify account:

https://mcp.apify.com/?tools=blueberry_rainstorm/pandapi-mcp-server

Or use the server's own URL with your Apify token as a bearer header:

URL:     https://blueberry-rainstorm--pandapi-mcp-server.apify.actor/mcp
Header:  Authorization: Bearer <your Apify token>

Add ?tools=markdown,pdf to the server URL to load only the tools you need. Details on the Pandapi MCP Server page.

Why it is different

  • Small: when we measured it, 13 tool definitions took 26,927 characters; the same actors loaded through Apify's generic MCP connection took 155,221. Less context spent before your first question.
  • Results in one call: the server waits for the run and returns rows, with no second "fetch dataset" step. Long jobs return a run ID to collect later.
  • Spend cap on every call (maxCostUsd, default $1) and small default sizes.

The server itself is free; each call costs that tool's own price on your Apify account, and Apify's free plan includes $5 a month.

Questions

How do I add the Pandapi MCP server to Claude?

Add a custom connector with the URL https://mcp.apify.com/?tools=blueberry_rainstorm/pandapi-mcp-server and sign in with Apify. It works in Claude, Cursor, VS Code and other remote MCP clients.

Is it free?

The server is free. Each tool call is billed at that API's per-result price on your Apify account, with a spend cap per call. Apify's free plan gives $5 of credit a month.

Can it read PDFs and websites for my agent?

Yes. The markdown tool reads pages, sitemaps and docs sites; the pdf tool reads PDFs including tables and scans.

How is it different from Firecrawl MCP?

Firecrawl MCP focuses on web scraping and search with a credit plan. This server adds PDFs, screenshots, reviews, tenders, jobs and postal codes, priced per result with no subscription.
