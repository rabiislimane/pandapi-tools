    How to use it

    1. Paste HTML into the left box, or copy part of a web page (Ctrl+C) and paste it there: the formatting comes over, not just the text.
    2. Leave Main content only on for whole pages. It keeps the article and drops navigation, sidebars, footers, cookie banners and ads.
    3. Add the page URL if the HTML has relative links, so links and images point to the right place.
    4. Copy the Markdown or download it as a .md file. For many files, drop them in the batch box and get a .zip.

    Questions

    Is my HTML uploaded anywhere?

    No. The conversion runs in your browser with open-source libraries (Turndown and Mozilla Readability). Nothing you paste or drop leaves your device, and the page works offline once it has loaded.

    What does "main content only" do?

    It uses Mozilla's Readability, the same engine as Firefox Reader View, to find the article in a full page and drop menus, footers, sidebars, cookie banners and ads. Snippets are converted as they are.

    Which Markdown flavor do I get?

    GitHub-flavored Markdown: # headings, - lists, ``` fenced code blocks with the language kept, pipe tables, ~~strikethrough~~ and task lists. Tables with merged cells stay as HTML, because Markdown tables can't merge cells.

    Is this good for ChatGPT, Claude or a RAG pipeline?

    Yes. Markdown keeps the structure that models use, at a fraction of the tokens of raw HTML. The tool shows a token estimate and can add YAML front matter with the title and source URL.

    Can it convert a whole website?

    This page converts the HTML you give it. To crawl many URLs or a sitemap, render JavaScript and get chunks for RAG, use the Web Page to Markdown API linked below.
