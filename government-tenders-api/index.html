If you watch one country, the official portal and its email alerts are enough. The work starts when you need several countries, the same keywords everywhere, and one spreadsheet.

The API way: one feed, one schema

  1. Open the Government Tenders API on Apify.
  2. Enter keywords (e.g. software, cybersecurity), countries, and optionally CPV, NAICS or UNSPSC codes, a minimum value and how many days must be left.
  3. Turn on onlyNew with a stateKey name to get only notices you haven't seen, and schedule the run daily on Apify.
  4. Send the results to Google Sheets, Slack or email with Apify's integrations, or call it from n8n, Make or code.
curl -X POST "https://api.apify.com/v2/acts/blueberry_rainstorm~public-tenders-feed/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "keywords": [
    "software",
    "cloud",
    "cybersecurity"
  ],
  "countries": [
    "US",
    "GB",
    "DE",
    "FR",
    "CA"
  ],
  "noticeTypes": [
    "tender",
    "pre-notice"
  ],
  "postedWithinDays": 7,
  "minDaysLeft": 10,
  "minValueUsd": 50000,
  "onlyNew": true,
  "stateKey": "it-tenders"
}'
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("blueberry_rainstorm/public-tenders-feed").call(run_input={
    "keywords": [
        "translation services"
    ],
    "sources": [
        "ted",
        "uk-fts",
        "canadabuys"
    ],
    "postedWithinDays": 3
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item["source"], item["title"], item.get("deadline"), item.get("valueUsd"))

What each notice looks like

Every source is mapped to the same fields: title, buyer, country, notice type (tender, pre-notice, award), published date, deadline and days left, estimated value in the original currency and in USD/EUR, CPV/NAICS/UNSPSC codes, set-aside (SAM), a description, the link to the official notice, and buyer contacts where the portal publishes them. Expired tenders are hidden by default.

What it costs

$2 per 1,000 notices, no start fee. A daily alert that finds 40 new notices costs $0.08 a day, about $2.40 a month. For comparison, commercial bid databases are sold as subscriptions (GovWin and similar tools are priced per seat per year). Apify's free $5 credit covers about 2,500 notices a month.

Limits

  • US state and local portals, Australia's AusTender and UNGM are not included yet.
  • Tender documents (attachments) are linked, not downloaded.
  • Smaller EU tenders below the EU thresholds only appear if the country also publishes them to TED.

Questions

Is there a free government tenders API?

Yes, each portal has one: SAM.gov (with an API key), TED, UK Find a Tender and Contracts Finder, CanadaBuys open data and the World Bank. They use different formats. The Pandapi feed combines them for $2 per 1,000 notices, and Apify's free credit covers about 2,500 notices a month.

How do I get daily tender alerts?

Turn on onlyNew with a stateKey, schedule the run daily on Apify, and add an email, Slack or Google Sheets integration. You only pay for new notices.

Can I filter by CPV or NAICS codes?

Yes. CPV prefixes work on TED and UK notices, NAICS and PSC on SAM.gov, UNSPSC and GSIN on CanadaBuys. Sources that can't apply a filter are skipped and the run says why.

Does it include contract awards?

Yes. Add award to noticeTypes to get awarded contracts with the winner and value where the portal publishes them.
