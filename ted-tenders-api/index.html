TED tenders API: how to search Tenders Electronic Daily from code

TED publishes every EU tender above the EU thresholds, and its search API is free with no key. This page shows a working request, the parts that take time (query syntax, multilingual eForms fields, de-duplication), and how to get TED as a clean daily feed instead.

The free way: the TED v3 search API

Send a POST to https://api.ted.europa.eu/v3/notices/search with an expert query, the fields you want and a page size. Search needs no API key (we checked on 22 November 2026); a key is only needed to submit notices.

import requests

body = {
    "query": 'FT~"cybersecurity" AND publication-date>=20261115',
    "fields": ["publication-number", "notice-title", "buyer-name", "buyer-country",
               "publication-date", "deadline-receipt-tender-date-lot", "classification-cpv", "links"],
    "limit": 50,
    "page": 1,
}
r = requests.post("https://api.ted.europa.eu/v3/notices/search", json=body, timeout=60)
for n in r.json()["notices"]:
    buyer = (n.get("buyer-name") or {}).get("eng") or next(iter((n.get("buyer-name") or {}).values()), [""])
    print(n["publication-number"], n.get("publication-date"), buyer[0])

A few things to know before you build on it:

TopicWhat you getWhat it means for you
Query syntaxTED's expert search language, e.g. FT~"software" AND buyer-country=DEUTest queries in TED's own expert search first; field names follow eForms
LanguagesText fields such as buyer-name come as an object keyed by languagePick a language and fall back to the first one present
Codesclassification-cpv is a list of CPV codesFilter by prefix (e.g. 72 for IT services) in the query or after
LinksXML, PDF and HTML links per languageStore the HTML link for people and the XML for parsing
RepeatsThe same query returns the same notices every dayKeep the publication numbers you have seen to alert only on new ones

If you only need EU tenders and like writing code, this is a good, free route.

The feed way: TED with keywords, CPV codes and only new notices

  1. Open the Government Tenders API on Apify.
  2. Set sources to ["ted"], add keywords and countries, and optionally CPV prefixes, a minimum value and the days left before the deadline.
  3. Turn on onlyNew with a stateKey so each run returns only notices you haven't seen, and schedule it daily.
  4. Send results to Google Sheets, Slack or email with Apify's integrations, or read them from n8n, Make or code.
curl -X POST "https://api.apify.com/v2/acts/blueberry_rainstorm~public-tenders-feed/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "sources": [
    "ted"
  ],
  "keywords": [
    "cybersecurity",
    "penetration testing"
  ],
  "countries": [
    "DE",
    "FR",
    "NL",
    "BE"
  ],
  "cpvCodes": [
    "72",
    "48"
  ],
  "postedWithinDays": 7,
  "minDaysLeft": 10,
  "onlyNew": true,
  "stateKey": "eu-security"
}'
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("blueberry_rainstorm/public-tenders-feed").call(run_input={
    "sources": [
        "ted"
    ],
    "keywords": [
        "translation services"
    ],
    "postedWithinDays": 3
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item["country"], item["title"], item.get("deadline"), item.get("valueUsd"))

Each notice comes back with the same fields as SAM.gov, UK and Canada notices: title, buyer, country, notice type, published date, deadline and days left, value in the original currency and in USD/EUR, CPV codes and the link to the official notice. Add "uk-fts" or "sam" to sources to watch more markets with the same query.

What it costs

The TED API is free. The feed costs $2 per 1,000 notices with no start fee, so a daily EU alert that finds 30 new notices costs about $0.06 a day. Apify's free $5 monthly credit covers about 2,500 notices.

Limits

  • TED covers tenders above the EU thresholds and what member states choose to publish there. Many smaller national tenders are only on national portals.
  • Tender documents are linked, not downloaded.

Questions

Is the TED API free?

Yes. The TED v3 search endpoint is free and searching needs no API key. You pay nothing to TED; you only spend time on the query syntax, multilingual fields and tracking which notices are new.

What is the TED API endpoint?

Search is a POST to https://api.ted.europa.eu/v3/notices/search with a JSON body holding an expert query, the fields to return, a limit and a page number.

How do I get daily alerts for new TED tenders?

Either store the publication numbers you've seen and compare each day, or use the Pandapi feed with onlyNew and a stateKey and schedule it daily on Apify, so each run returns only new notices.

Can I filter TED tenders by CPV code?

Yes. Use classification-cpv in a TED query, or pass CPV prefixes such as 72 (IT services) in cpvCodes to the Pandapi feed.
