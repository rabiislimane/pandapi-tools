PDFShift, DocRaptor and wkhtmltopdf alternatives for HTML to PDF

wkhtmltopdf was the default for years; it's archived now and its old WebKit doesn't understand modern CSS. The replacements are headless Chrome (do it yourself), a hosted API with a monthly plan, or a pay-per-PDF API.

Updated 21 November 2026 · by the Pandapi team · We make one of the tools compared here, so we list where the others are better too.

What makes Pandapi different

  • Template + data: a Handlebars template and an array of rows give one PDF per row, named from your data (invoices, certificates, reports).
  • No plan: 500 invoices a month cost $1.50; failed documents are free.
  • Page count doesn't matter: a 40-page report costs the same as a 1-page invoice.

Choose PDFShift or DocRaptor if you convert on demand inside a web request and need an answer in a second, or if you need Prince-level print typography.

Questions

What replaced wkhtmltopdf?

Most projects moved to headless Chrome (Puppeteer or Playwright), Gotenberg for a self-hosted API, or a hosted HTML to PDF API.

Is PDFShift free?

It gives 50 free credits a month, per its FAQ, with paid plans for more.

How do I make 1,000 invoices as PDFs?

Write one HTML invoice template with Handlebars placeholders, put the 1,000 invoices in a JSON array, and run the HTML to PDF API. It costs $3.
