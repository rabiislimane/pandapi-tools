Export Google Play reviews to CSV, with developer replies

Play Console exports your own reviews as monthly CSV files. For competitor apps, or several languages at once, you need something else. Here's the free route, where it breaks, and the no-code route.

Updated 21 November 2026 · by the Pandapi team

Google Play Reviews Scraper: $0.10 per 1,000 reviews. Apify's free plan gives you $5 of credit every month, which covers about 50,000 reviews a month. No start fee; failed items are free.

Try Google Play Reviews Scraper

Free way 1: Play Console (your own app)

Play Console › Ratings and reviews › Reviews has a download, and monthly review reports land in your Cloud Storage bucket. One CSV per app per month, your apps only.

Free way 2: the google-play-scraper library

pip install google-play-scraper

from google_play_scraper import Sort, reviews
result, _ = reviews("com.duolingo", lang="en", country="us", sort=Sort.NEWEST, count=2000)

Works for any public app. Where it breaks: one language per call (German reviews need a second pass), no memory between runs, and when Google changes its page format the library breaks until someone patches it. You also keep it running yourself.

The API way

  1. Open the Google Play Reviews Scraper on Apify.
  2. Paste Play Store links, package IDs or app names. Add several languages and countries: results are merged without duplicates.
  3. Filter by stars, date, keywords or app version, so you only pay for the reviews you need.
  4. Turn on onlyNewReviews and schedule it: each run returns only reviews written since the last one.
curl -X POST "https://api.apify.com/v2/acts/blueberry_rainstorm~google-play-reviews-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "apps": [
    "https://play.google.com/store/apps/details?id=com.duolingo"
  ],
  "languages": [
    "en",
    "de",
    "fr"
  ],
  "countries": [
    "us"
  ],
  "maxReviewsPerApp": 2000,
  "minRating": 1,
  "maxRating": 3
}'
# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("blueberry_rainstorm/google-play-reviews-scraper").call(run_input={
    "apps": [
        "com.spotify.music"
    ],
    "maxReviewsPerApp": 1000,
    "keywords": [
        "crash",
        "battery"
    ]
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    if item.get("type") == "review":
        print(item["rating"], item["text"][:80], item.get("developerReply"))

What you get

Rating, text, date, app version, thumbs-up count, the developer's reply and its date, language and country. Optional app details (installs, rating histogram, Data safety, similar apps), search and top charts. A free per-app summary shows rating by version and language, developer reply rate and median reply time, and top complaint phrases. Reviewer names are not stored.

What it costs

$0.10 per 1,000 reviews, no start fee. 10,000 reviews cost $1. Apify's free credit covers about 50,000 reviews a month.

Questions

How do I export Google Play reviews?

For your own app, use Play Console's review download or monthly reports. For any app, use the google-play-scraper library or the Pandapi API, which handles several apps and languages in one run for $0.10 per 1,000 reviews.

Can I get reviews in all languages?

Yes. Google Play splits reviews by language; list the languages you need and the API merges them without duplicates.

Do I get developer replies?

Yes, with the reply text and date, and the free summary reports reply rate and median reply time.

How do I monitor new reviews?

Turn on onlyNewReviews and schedule the run on Apify. Later runs return only reviews written since the previous run, so you pay only for new ones.
